# Julio Guilherme — Portfólio

Portfólio pessoal de desenvolvimento de software, automação e inteligência artificial.

## Tecnologias

React, TypeScript, Vite, Tailwind CSS e Base UI. Aplicação estática, sem backend ou credenciais de serviços.

## Desenvolvimento

Requer Node.js 22 ou superior.

```sh
npm ci
npm run dev
```

## Publicação

```sh
npm run build
npm run preview
```

Publique o conteúdo de `dist/` em uma hospedagem estática. Para uma subpasta, defina `BASE_PATH` antes do build (por exemplo, `/julio-guilherme-portfolio/`).
